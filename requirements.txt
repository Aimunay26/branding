# Dependencias de ejecución, con la versión fijada.
#
# Por qué van fijadas y no sueltas: estas son EXACTAMENTE las versiones con las
# que el proyecto está probado (`pip freeze` del entorno que funciona). Sin el
# «==», un `pip install -r` de dentro de seis meses trae otra cosa y el fallo
# aparece en sitios que no se parecen a la causa: el SDK de anthropic cambia la
# superficie de `messages.parse`, pydantic 3 rompe los `Literal` del esquema y
# weasyprint sube de major sin avisar. Subir una versión es una decisión, no un
# efecto secundario de instalar.
#
# Para actualizar algo: cámbialo aquí, ejecútalo, y si pasa la suite de pruebas
# (requirements-dev.txt) se queda.
